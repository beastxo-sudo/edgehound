# EdgeHound / 60-Second Lab — closed

This project tested whether short-horizon Bitcoin direction markets on Polymarket
contained a tradeable edge. It was shut down 2026-07-22 after a full-coverage
reconstruction from Polymarket's own price history showed no edge (z ≈ 0.7).

An earlier apparent edge (z ≈ 8.5) in live-sampled data was traced to coverage
bias: the sampler's uptime correlated with favorable windows. Lesson kept;
everything else removed. History remains in git if ever needed.
